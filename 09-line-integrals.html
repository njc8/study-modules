Chapter 1 · Stewart 16.1

Vector fields

A vector field attaches a vector to every point. Wind, current, gravity, and electric force are all vector fields.

A vector field on a region of the plane is a function that eats a point and returns a vector:

\(\mathbf{F}(x,y)=\langle P(x,y),\,Q(x,y)\rangle=P(x,y)\,\mathbf{i}+Q(x,y)\,\mathbf{j}\)\(P\) and \(Q\) are ordinary scalar functions, called the component functions. In space there is a third one: \(\mathbf{F}(x,y,z)=\langle P,Q,R\rangle\).

To sketch one, pick a handful of points, evaluate \(\mathbf{F}\) there, and draw each answer as an arrow whose tail sits at the point you used. That last part is the whole trick. The arrow at \((1,0)\) tells you about the field at \((1,0)\), not about the origin.

Four patterns cover most of the pictures you will meet:

  • Rotation. \(\mathbf{F}=\langle -y,x\rangle\) is perpendicular to the position vector \(\langle x,y\rangle\) at every point, so the arrows circle the origin counterclockwise and grow with the distance. \(\langle y,-x\rangle\) circles clockwise.
  • Radial. \(\mathbf{F}=\langle x,y\rangle\) is the position vector itself: every arrow points straight away from the origin. \(\langle -x,-y\rangle\) points straight in, like gravity.
  • Shear. \(\mathbf{F}=\langle y,0\rangle\) is horizontal everywhere, to the right above the \(x\)-axis and to the left below it. This is how water in a channel moves.
  • Constant. \(\mathbf{F}=\langle a,b\rangle\) is the same arrow everywhere: a steady wind.

Gradient fields

You already know one factory for vector fields: the gradient. If \(f(x,y)\) is a scalar function, then

\(\nabla f(x,y)=\langle f_x(x,y),\,f_y(x,y)\rangle\)The gradient vector field of \(f\). In space, \(\nabla f=\langle f_x,f_y,f_z\rangle\). A field that equals some \(\nabla f\) is called conservative, and \(f\) is its potential function.

Gradient fields have a look you can spot. The gradient points in the direction of fastest increase of \(f\), and it is perpendicular to the level curve of \(f\) through that point. So the arrows of \(\nabla f\) cross the contour map of \(f\) at right angles, always pointing from lower contours toward higher ones, and they are longest where the contours are packed tightest.

In space a vector field \(\mathbf{F}(x,y,z)=\langle P,Q,R\rangle\) is drawn the same way, with one arrow in space at each point. The three component functions may depend on all three variables. Everything in this module works the same in two and three dimensions except for the conservative test, which gets an extra piece in Chapter 3.

Which fields are gradients? Not all of them. If \(\mathbf{F}=\nabla f=\langle f_x,f_y\rangle\), then \(P_y=f_{xy}\) and \(Q_x=f_{yx}\), and mixed partials are equal. So a gradient field must satisfy \(P_y=Q_x\). A rotation field fails it: for \(\langle -y,x\rangle\), \(P_y=-1\) but \(Q_x=1\). Arrows that run in closed loops cannot be climbing a hill.
Arrow lengths are scaled. Every plotter (including the one above) multiplies all arrows by one common factor so that they fit between grid points. Compare arrow lengths with each other, never against the coordinate grid, and never read the tip of an arrow as a location.

Line integrals of vector fields

This is the work integral. Only the part of the force that points along the motion counts.

A constant force \(\mathbf{F}\) moving an object through a displacement \(\mathbf{D}\) does work \(\mathbf{F}\cdot\mathbf{D}\). When the force varies and the path bends, chop the path into tiny displacements \(d\mathbf{r}=\mathbf{r}'(t)\,dt\), dot each with the force there, and add:

\(\displaystyle W=\int_C \mathbf{F}\cdot d\mathbf{r}=\int_a^b \mathbf{F}\big(\mathbf{r}(t)\big)\cdot\mathbf{r}'(t)\,dt\)Substitute the curve into \(\mathbf{F}\), dot with the velocity, integrate. No square roots: the speed does not appear on its own.

Write \(\mathbf{r}'(t)\,dt=\langle dx,dy\rangle\) and the dot product becomes the differential form of the same integral:

\(\displaystyle\int_C \mathbf{F}\cdot d\mathbf{r}=\int_C P\,dx+Q\,dy\qquad\text{and in space}\qquad \int_C P\,dx+Q\,dy+R\,dz\)Same integral, different notation. To evaluate it, put \(x=x(t),\,y=y(t),\,dx=x'(t)\,dt,\,dy=y'(t)\,dt\) and integrate in \(t\).

There is a third way to read it. Since \(\mathbf{T}=\mathbf{r}'/|\mathbf{r}'|\) is the unit tangent and \(ds=|\mathbf{r}'|\,dt\),

\(\displaystyle\int_C\mathbf{F}\cdot d\mathbf{r}=\int_C (\mathbf{F}\cdot\mathbf{T})\,ds\)The work integral is the scalar line integral of the tangential component of \(\mathbf{F}\). Where \(\mathbf{F}\) is perpendicular to the curve it contributes nothing.

Orientation matters here. Reversing the curve reverses every \(d\mathbf{r}\), so every dot product flips sign:

\(\displaystyle\int_{-C}\mathbf{F}\cdot d\mathbf{r}=-\int_{C}\mathbf{F}\cdot d\mathbf{r}\qquad\text{while}\qquad \int_{-C}f\,ds=\int_{C}f\,ds\)

And as before, a path made of several pieces is handled one piece at a time and the results are added.

    The Fundamental Theorem and conservative fields

    For a special class of fields the integral does not depend on the path at all. You only need the endpoints.

    A vector field \(\mathbf{F}\) is conservative if it is the gradient of some scalar function: \(\mathbf{F}=\nabla f\). That function \(f\) is called a potential function for \(\mathbf{F}\). For such fields, work is a difference of two numbers:

    \(\displaystyle\int_C \nabla f\cdot d\mathbf{r}=f\big(\mathbf{r}(b)\big)-f\big(\mathbf{r}(a)\big)=f(\text{end})-f(\text{start})\)The Fundamental Theorem for line integrals. It is the chain rule run backwards: \(\frac{d}{dt}f(\mathbf{r}(t))=\nabla f\cdot\mathbf{r}'(t)\), so the integral of the right side is the net change in \(f\).

    Three consequences follow immediately.

    • Path independence. Any two paths from \(A\) to \(B\) give the same answer, because both give \(f(B)-f(A)\). The shape of the path is irrelevant.
    • Closed curves give zero. If \(C\) starts and ends at the same point, \(f(\text{end})-f(\text{start})=0\). Write \(\oint_C\nabla f\cdot d\mathbf{r}=0\).
    • Reversal flips the sign, as always, since \(f(A)-f(B)=-(f(B)-f(A))\).

    Is this field conservative?

    In the plane, on a domain with no holes in it (a simply connected region, such as all of \(\mathbb{R}^2\) or a disc), there is a clean test:

    \(\mathbf{F}=\langle P,Q\rangle\ \text{is conservative}\iff \dfrac{\partial P}{\partial y}=\dfrac{\partial Q}{\partial x}\)Necessary always, and sufficient when the domain is simply connected. Compute both partials and compare.

    In space the same idea needs three equations, which are packaged as the curl (the subject of Module 10):

    \(\operatorname{curl}\mathbf{F}=\langle R_y-Q_z,\;P_z-R_x,\;Q_x-P_y\rangle,\qquad \mathbf{F}\ \text{conservative}\iff \operatorname{curl}\mathbf{F}=\mathbf{0}\)Three cross-partial equalities at once: \(R_y=Q_z\), \(P_z=R_x\), \(Q_x=P_y\). The last one is exactly the 2D test.

    Finding the potential function

    Once you know \(\mathbf{F}\) is conservative, recover \(f\) by partial integration. Integrate \(P\) with respect to \(x\), treating \(y\) as a constant. The "constant" of integration can be any function of \(y\), so call it \(g(y)\). Differentiate the result with respect to \(y\), set it equal to \(Q\), solve for \(g'(y)\), and integrate once more. In space there is one extra round with \(R\) and \(z\).
