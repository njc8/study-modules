How the trainer decides what to show you

The design follows what the memory research says works: active recall, spaced repetition, no recognition-based multiple choice, and honest self-grading only where a machine cannot grade.

1. Retrieve, do not recognizeEvery card asks you to produce the fact: type the antiderivative, the series, the formula. Recognizing a correct option in a list feels like knowing and is not, so there are no multiple-choice cards.
2. Machine grading where possibleTyped answers are graded by the same checkers as the module drills: any algebraically equivalent form is accepted, and an added constant of integration is fine.
3. Self-grading for statementsCards like "state the ratio test" ask you to write it out, then reveal the answer. Rate yourself Again if any condition was missing. Being strict here is what makes the schedule work.
4. SpacingA new card returns tomorrow, then in 3 days, then the gap multiplies (about 2.5 times) on every Good. Easy grows the gap faster. Hard grows it a little. Again sends the card back into the current session and shortens future gaps.
5. Nothing you already knowA card you answer Easy repeatedly is soon weeks away. "I know this cold" parks a card for 45 days, then audits it once. Cards with intervals of three weeks or more count as mastered.
6. InterleavingDue cards from every enabled module are shuffled together, so retrieval happens without the context clue of the chapter you are in, which is exactly how exams ask.
