**Idea:** If the limit exists, it must be the same along *every* path through the origin. Two common paths that often disagree: \(y = 0\) and \(y = x\). If they disagree, the limit **does not exist**. If they agree, try to *prove* existence — usually with the Squeeze Theorem.

---

## (a) \(\displaystyle \lim_{(x,y)\to(0,0)} \frac{xy}{x^2+y^2}\)

**Along \(y = 0\):**
\[
\frac{x\cdot 0}{x^2+0} = 0 \quad\text{so the limit is } 0.
\]

**Along \(y = x\):**
\[
\frac{x\cdot x}{x^2+x^2} = \frac{x^2}{2x^2} = \frac{1}{2}.
\]

Two paths give different values (\(0\) vs. \(\tfrac12\)).

**Conclusion:** The limit **does not exist**.

*Check:* The function is homogeneous of degree 0 (numerator degree 2, denominator degree 2), so along every line \(y=mx\) you get \(\frac{mx^2}{x^2(1+m^2)} = \frac{m}{1+m^2}\) — depends on \(m\), confirming failure.

---

## (b) \(\displaystyle \lim_{(x,y)\to(0,0)} \frac{x^2 y}{x^2+y^2}\)

**Along \(y = 0\):** value is \(0\). **Along \(y = x\):** \(\frac{x^3}{2x^2} = \frac{x}{2} \to 0\). Lines suggest the limit is \(0\), but that's not a proof.

\[
\left|\frac{x^2 y}{x^2+y^2}\right| \le \frac{x^2 |y|}{x^2} = |y| \quad\text{(since } x^2+y^2 \ge x^2\text{)}

and \(|y| \to 0\) as \((x,y)\to(0,0)\). So by squeezing,
\[
\lim_{(x,y)\to(0,0)} \frac{x^2y}{x^2+y^2} = 0.
\]

*Alternate check:* Polar coordinates: \(\frac{r^3\cos^2\theta\sin\theta}{r^2} = r\cos^2\theta\sin\theta\), and \(|r\cos^2\theta\sin\theta| \le r \to 0\) **uniformly in \(\theta\)** — that uniform bound is what makes the proof valid.
